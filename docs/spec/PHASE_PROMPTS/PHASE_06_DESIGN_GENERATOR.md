# PHASE 06 — Six-Screen Concept Generator

Read `08_AI_DESIGN_ENGINE.md`, `09_PROPOSALS_AND_PREVIEWS.md`, `11_SECURITY.md`, `15_TESTING_QA.md`.

## Work
1. Deterministic renderer driven by validated design JSON and allowlisted component vocabulary.
2. Six responsive screens with industry adaptation: Home, Services/Products, About, Industry-specific trust/process, Inquiry/Booking demo, Contact.
3. Consistent design tokens, mobile-first layout, semantic headings, accessible labels/focus, reduced motion and sensible navigation.
4. Licensed/original assets with provenance; no hotlinks or unauthorized logos/fonts.
5. Separate verified facts/proposed copy/assumptions; no fabricated testimonials, awards, staff, certifications or metrics.
6. Visible notice: “Independent redesign concept — not the official website”.
7. Demo forms never submit or collect prospect data.
8. Version generated design and preserve rollback/regeneration.
9. Disposable sandbox, no secrets/internal network. Prefer fixed renderer/approved components over arbitrary generated code.
10. Cost ceilings and cancellation.

## Tests
All six pages; coherent content; no fake proof; asset license metadata; inert forms; mobile/desktop; content injection; sandbox isolation. Stop if sandbox cannot be proven.

## Deliverable
Six-screen concept builder and owner preview/review workflow. **Stop after Phase 06.**
