# PHASE 07 — Responsive Validation and Screenshots

Read `08_AI_DESIGN_ENGINE.md`, `09_PROPOSALS_AND_PREVIEWS.md`, `15_TESTING_QA.md`.

## Work
1. Validate at desktop, tablet and mobile viewports.
2. Check routes, navigation, missing images/fonts, console errors, overflow, heading order, accessible names, focus, contrast and demo form behavior.
3. Verify consistent design tokens/content across all six screens.
4. Capture clean high-resolution screenshots for all six pages and required viewports.
5. Produce actionable pass/fail/unknown report with evidence.
6. Bounded repair loop for deterministic renderer problems; no infinite AI regeneration.
7. Mark ready only when critical checks pass; otherwise needs revision/manual review.
8. No debug overlays, file paths or secrets in screenshots.

## Tests
Layout overflow, broken routes/images, contrast/focus issues, missing page, console error and screenshot/version mismatch fixtures. Verify artifact hashes/version.

## Deliverable
Validation worker, screenshots and report. **Stop after Phase 07.**
