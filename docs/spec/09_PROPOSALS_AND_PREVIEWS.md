# 09 — Proposal PDF and Live Preview

## Deliverables

For each approved concept version:
- Six full-page PNG screenshots, one per screen.
- One professional PDF proposal.
- One unique live preview URL.
- One concise redesign summary.
- One personalized outreach draft (not sent until eligible).

## Recommended PDF structure

1. Cover: “Website Redesign Concept for [Business]”; clearly identify it as an independent concept prepared by Muhammad Aqib.
2. Current website observations: evidence-based, dated and scoped.
3. Proposed design direction: colors, typography, layout, journey and rationale.
4. Six page previews, each labelled with purpose.
5. Proposed information architecture.
6. Potential improvements framed as UX opportunities, not guaranteed conversions/SEO/revenue.
7. Developer introduction: Muhammad Aqib, Website Developer, https://aqibkhn.space, https://github.com/10-aqib.
8. Next step with owner-supplied contact information.

Do not invent phone, postal address, company registration, years of experience, client list or testimonials.

## Preview behavior

- Visible notice: “Independent website redesign concept — not the official website of [Business].”
- No implied endorsement, partnership, ownership or authorization.
- Static/read-only; demo forms inert and non-collecting.
- No real payments, bookings, logins, customer records or production business operations.
- Unique random token with at least 128 bits entropy; store only token hash.
- Default expiry 30 days; owner can revoke immediately.
- No predictable IDs or directory listing.
- Separate origin from dashboard/API, strict CSP/security headers, no source maps/secrets/internal services.
- Noindex/nofollow where appropriate; no prospect PII in URLs.
- Neutral preview branding; do not impersonate the business.

## Validation before proposal-ready

All six screenshots match the current design version; PDF opens and includes expected content/pages; no blank pages/placeholders/debug output; valid unexpired token opens externally; expired/revoked token fails safely; external links work; concept notice appears; no secrets, internal IDs or private notes leak.

## Sharing and deletion

Prefer a secure preview link and PDF over six oversized attachments. Owner can revoke/delete. Apply storage lifecycle and expiry cleanup while retaining only metadata needed for audit.
